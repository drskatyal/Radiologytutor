# Fly.io + R2 ops notes

## Apps
- `fly.toml` — Next.js (`flowrad-learn`)
- `fly.orthanc.toml` — Orthanc (`flowrad-orthanc`) with volume `orthanc_data`

Set on the app:
```
ORTHANC_URL=http://flowrad-orthanc.internal:8042
ORTHANC_USER=flowrad
ORTHANC_PASSWORD=…
MONGODB_URI=…
BETTER_AUTH_SECRET=…
BETTER_AUTH_URL=https://<app>.fly.dev
GOOGLE_CLIENT_ID=…
GOOGLE_CLIENT_SECRET=…
R2_ACCOUNT_ID=…
R2_ACCESS_KEY_ID=…
R2_SECRET_ACCESS_KEY=…
R2_BUCKET=flowrad
R2_PUBLIC_BASE_URL=https://cdn.example.com
GEMINI_API_KEY=…
```

Create Orthanc volume once: `fly volumes create orthanc_data -a flowrad-orthanc --size 50`
