# M1 examiner isolation

Exam pages render a branded imaging-only projection in a separate client. Attempts pin a private server-only key document; text/report answers are structured without keys and scored deterministically, and point scoring requires the exact SOP/frame. No per-item score is returned until the attempt closes. The opening view is neutral. Active attempts gate case/findings/pack/prefetch/catalog/tutor/check-in/Live-token routes, and report grading cannot bypass exam scoring by requesting practice mode. Practice feedback is explicitly labelled.

The exam component uses the existing dark viewer, form and badge components; errors are announced and field-associated, and submit has disabled/busy states. No direct Live/audio provider path is exposed for examinations. PHI/media-specific hardening follows in the addendum.
