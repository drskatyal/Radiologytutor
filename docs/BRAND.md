# FlowRad Learn — Brand

Domain-authentic radiology identity. Not generic AI SaaS.

## Mark

A **film-window reticle + caliper** (`components/brand/BrandMark.tsx`):
crosshair for localization, ticks for windowing. Always on film black
(`bg-imaging`), amber stroke.

## Wordmark

**FlowRad** in Source Serif 4 (semibold). **Learn** quieter, secondary weight.
Never Inter / Roboto / Space Grotesk.

## Palette

| Token | Role |
|-------|------|
| Canvas / surface / elevated | Warm charcoal reading-room ladder |
| Accent `#d4a84b` | Film-marker amber — primary action only |
| Imaging `#000` | DICOM / film planes |
| Paper text `#f2ede6` | Primary type on charcoal |

No purple gradients. No neon cyan. No glow washes.

## Surfaces

- **Marketplace** — brand-first hero (full-bleed film), editorial list rows below.
- **Library** — same editorial rows; film plane as visual anchor for cases.
- **Reading room** (`/case/*`) — chrome hidden; DICOM is the composition.
- **Auth** — film atmosphere behind the form; no card chrome.

## Layout rules

- Prefer **hairline rows** over bordered cards on catalog surfaces.
- One job per section. No pill clusters or stat strips in the hero.
- Trust signals (verified badge, credentials) are first-class, not stickers.
